# Job Tracker Frontend

A React frontend for the Job Tracker application, built with Vite and TypeScript.

## Tech Stack

- React 19
- TypeScript
- Vite
- React Router
- Axios
- Recharts

## Features

- User registration and login
- JWT authentication with protected routes
- View all job applications
- Add, edit, and delete applications
- Application status tracking (Applied, Interview, Offer, Rejected)
- Statistics dashboard with pie chart and conversion rates

## Getting Started

### Prerequisites

- Node.js 18+
- Job Tracker API running on http://localhost:5015

### Run the application

1. Clone the repository:
   git clone https://github.com/kirca01/job-tracker-frontend.git
   cd job-tracker-frontend

2. Install dependencies:
   npm install

3. Start the development server:
   npm run dev

4. Open http://localhost:5173
